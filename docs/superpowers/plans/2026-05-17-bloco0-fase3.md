> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Validar o seed CE do staging Railway, executar smoke test completo, e construir a fundação documental do Bloco 0: entidade Person, expansão de Source, Evidence e Contestation, e criação de Chain of Transformation — sem novos conectores, sem Neo4j, sem score automático.

**Architecture:** O backend .NET 8 segue Clean Architecture (Domain/Application/Infrastructure/API). Todas as entidades herdam de `AuditableEntity` (Guid Id, CreatedAt, UpdatedAt, DeletedAt, SourceUpdatedAt) com soft delete via global query filter. Migrations EF Core são aplicadas automaticamente no startup via `MigrateOnStartup=true` no Railway. Novos campos são SEMPRE nullable ou com default seguro para não quebrar ETL existente.

**Tech Stack:** .NET 8, Entity Framework Core, PostgreSQL (Railway staging), psycopg2 (validação), PowerShell (comandos), dotnet ef CLI.

**Regras permanentes:**
- NUNCA hardcodar `DATABASE_URL` ou senha em arquivo versionado
- NUNCA modificar `load()` dos pipelines existentes
- NUNCA criar inferência, score ou narrativa política
- Todos os novos campos de entidade: nullable ou com default — zero breaking changes no ETL
